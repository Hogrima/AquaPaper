# AquaPaper 1.1 — 멀티 모니터 검증

2026-09-18, 현재 Windows 11 PC의 실제 모니터 3대에서 확인했습니다.

- 실제 물리 배치: 모니터 3 (-1920, 0), 모니터 2 (0, 0, 주 화면), 모니터 1 (1920, 0). 각각 1920×1080. Windows 배율과 관계없이 물리 좌표로 창 크기와 커서를 처리합니다.
- 한 화면만: 1·2·3번을 각각 선택하여 목표 위치·크기, 바탕화면 부모 연결 확인.
- 모두 이어서: 창 1개, 전체 5760×1080, 모니터별 커서 좌표 변환 및 GPU 오류 없음 확인.
- 화면마다 따로: 창 3개, 각 1920×1080, 해당 모니터에만 커서 활성화 확인.
- 검사 중 단일·연결·개별 모드 모두 60fps 측정. 실제 성능은 GPU·전원 상태와 화면 수에 따라 달라집니다.
- 모든 창 동시 일시정지·재개, 빠른 전환에서 마지막 선택 반영, 해제 후 창 정리 확인.
- C# 순수 배치 테스트 16개 조건: 음수 원점, 서로 다른 높이, 모니터 분리 시 대체 화면, 재연결, 경계 좌표 연속성 등.
- Node 테스트 11개: 기존 물고기 시뮬레이션 7개, 배치도와 다중 화면 렌더링 해상도 4개.

실제 모니터 케이블을 분리하거나 Windows 배치 설정을 바꾸지는 않았습니다. 연결 해제·세로 배치·빈 영역은 합성 배치 테스트로 확인했습니다.

재현 명령과 기능 설명은 루트 `README.md`를 참고하세요. 원본 통합 결과는 개발 폴더의 `artifacts/multi-monitor/smoke-test.json`과 PNG 파일입니다.
