# AquaPaper v1.5.0

## 한국어

- 환경 설정에서 **강가의 숲 · 입체**와 **열대 산호 수조** 배경을 선택할 수 있습니다. 선택은 자동 저장됩니다.
- 강가의 숲은 서로 다르게 그린 6개 투명 레이어와 좌우가 다른 수초를 사용합니다. 잎 끝은 물 흐름에 따라 부드럽게 흔들립니다.
- 열대 산호 수조는 먼 암초와 협곡을 포함한 이미지 10장을 독립된 깊이로 배치합니다.
- Blender로 제작한 산호 물고기 5종을 추가했습니다: 흰동가리, 노란양쥐돔, 블루탱, 무어리시 아이돌, 난쟁이매.
- 종마다 군집, 탐색, 암초 주변 체류, 아이돌 짝 유영, 난쟁이매의 암초 휴식 등 서로 다른 행동을 적용했습니다.
- 기존 수중 정원과 담수 어종 설정도 계속 선택할 수 있습니다.

## English

- Added **River forest · layered** and **Tropical coral reef** as selectable, automatically saved aquarium backgrounds.
- River forest uses six separately authored transparent planes, asymmetric left/right plants and gentle current-driven leaf sway.
- Tropical reef combines ten independently positioned plates, including distant ridges, spires, an arch and a receding canyon.
- Added five original Blender fish: clownfish, yellow tang, blue tang, Moorish idol and dwarf hawkfish.
- Species have distinct schooling, exploration, reef use, idol pairing and hawkfish perching behaviors.
- The original underwater garden and freshwater fish remain available.

Native verification of the new backgrounds used a single display. Multi-monitor rendering of these scenes needs separate validation.

The Windows x64 portable ZIP and SHA-256 checksum are attached to this release.
