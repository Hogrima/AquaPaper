# AquaPaper v1.2.0

## 한국어

물속의 작은 숲을 기본 장면으로 유지하면서, 기본 물고기 표현을 입체적인 **3D 네온테트라**로 확장했습니다.

- 화면 제목: **물속의 작은 숲** / *A Little Forest Underwater*
- 부제: **천천히 흐르는 빛, 자유롭게 헤엄치는 생명.** / *Slowly flowing light, life swimming freely.*
- 환경 설정에서 **한국어 / English**를 선택할 수 있습니다.
- 언어, 물고기 표현, 물고기 수, 조명, 속도, 상호작용, 입자, 품질 설정을 자동 저장합니다.
- 새 설치와 값이 없는 기존 설정의 기본 물고기 표현은 **3D 네온테트라**입니다. **기존 모드**도 선택할 수 있습니다.
- 원본 Blender 메시, 경량 LOD, GLB, 재현 스크립트와 동작 근거 문서를 포함합니다.

설정 파일은 `%LOCALAPPDATA%\AquaPaper\settings.json`에 저장됩니다. 모니터 배치 설정은 기존처럼 `display-settings.json`에 저장됩니다.

## English

The calm underwater forest now ships with **3D neon tetra** as the default fish appearance.

- Scene title: **A Little Forest Underwater**
- Subtitle: **Slowly flowing light, life swimming freely.**
- Choose **Korean / English** in Settings.
- Language, fish appearance, population, lighting, speed, interaction, particles and quality are saved automatically.
- New installs and settings without a fish-mode value default to **3D neon tetra**. The **Classic** mode remains available.
- Includes the original Blender mesh, lightweight LOD, GLB export, rebuild script and behavior notes.

Preferences are stored in `%LOCALAPPDATA%\AquaPaper\settings.json`; monitor layout remains in `display-settings.json`.
