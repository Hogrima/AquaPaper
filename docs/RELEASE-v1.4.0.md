# AquaPaper v1.4.0

## 한국어

- 기존 배경을 6개 깊이 레이어로 나누어 시점 이동과 2.5D 시차를 추가했습니다.
- 일렁이는 수면, 자연광·노을·달빛 반사, 기포와 흐르는 부유물을 선택적으로 사용할 수 있습니다.
- 각 효과는 저장되며, 전체 일시정지는 물고기·시점·물결·입자를 함께 멈춥니다.
- 네온테트라와 러미노즈 테트라의 개체별 군집·탐색·정지·낮은 수심 행동과 긴 활주를 개선했습니다.
- 카메라 이동을 물고기·플레코의 커서 판정에도 반영하고 WebView2 캡처 검사를 안정화했습니다.

## English

- Added six depth-masked layers with camera drift and 2.5D parallax.
- Added optional rippling surface water, day/dusk/moonlit reflections, bubbles and drifting suspended particles.
- Each effect is saved; pause freezes fish, camera, water and particles together.
- Improved per-fish school, exploration, hovering and low-water behaviors plus longer glides for neon and rummy-nose tetras.
- Applied camera offsets to fish and pleco cursor picking and bounded WebView2 capture checks.

The Windows x64 portable ZIP and SHA-256 checksum are attached to this release.
