# AquaPaper v1.3.0

## 한국어

- Windows 로그인 시 저장된 수족관을 자동 적용하는 시작 기능을 추가했습니다.
- 물고기, 수조, 화면, 일반 설정을 탭으로 나누고 언어·어종·배치를 저장합니다.
- 러미노즈 테트라와 비파·플레코를 추가·제거할 수 있습니다.
- 플레코는 데스크톱 전체 최대 8마리이며, 여러 화면에 자동 분배됩니다.
- 3D 네온테트라 기본값, 한국어/English UI, 기존 모드를 유지합니다.

## English

- Added Windows startup restoration for the saved aquarium.
- Grouped fish, aquarium, display and general settings into tabs, with saved language, species and layout choices.
- Added add/remove controls for rummy-nose tetras and sailfin plecos.
- Plecos are capped at eight across the desktop and allocated across separate displays.
- Keeps the 3D neon tetra default, Korean/English UI, and the classic mode.

The Windows x64 portable ZIP and SHA-256 checksum are attached to this release.
