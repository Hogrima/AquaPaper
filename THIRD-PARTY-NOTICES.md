# Third-party components

AquaPaper uses Microsoft WebView2 SDK 1.0.3719.77 and the user's separately installed Microsoft Edge WebView2 Runtime. The SDK license and notice are included in `licenses/WebView2/` in the portable distribution. See https://www.nuget.org/packages/Microsoft.Web.WebView2/1.0.3719.77.

The portable distribution contains Microsoft .NET 10 runtime components. The .NET runtime license and third-party notices are included in `licenses/dotnet/`. Sources: https://github.com/dotnet/runtime and https://github.com/dotnet/winforms.

The aquarium scenery was generated specifically for this project with the built-in imagegen tool. The fish, particles, shaders and application UI were implemented in this project. No stock photos, downloaded fish assets, external JavaScript libraries or remote fonts are loaded by the application.
